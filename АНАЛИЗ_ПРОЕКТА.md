# Анализ проекта EDM (Entity Data Model)

## 1. Общее описание проекта

**EDM (Entity Data Model)** - клиент-серверная библиотека для Node.js, предназначенная для разработки трехзвенных приложений с использованием SQL-ориентированных баз данных (PostgreSQL, SQLite).

### Основное назначение
Библиотека предоставляет инструменты для:
- Описания модели данных в декларативном стиле
- Автоматической генерации структуры базы данных из модели
- Создания объектно-ориентированного слоя для работы с данными (ORM-подобный функционал)
- Упрощения клиент-серверного взаимодействия с данными
- Автоматической генерации SQL-запросов
- Управления конфигурациями и справочниками

### 2.2. Основные компоненты

#### Серверная часть (`server/`)
- **`edm.js`** - Ядро библиотеки: классы `EDMObj` и `EDMData`
- **`model.js`** - Система описания модели данных (DSL)
- **`helpers.js`** - Вспомогательные функции для работы с настройками, параметрами, JSON
- **`utils.js`** - `DataController` - универсальный контроллер для CRUD-операций
- **`client.js`** - Клиентские хелперы для десериализации

#### Модули базы данных (`server/db/`)
- **`proto.js`** - Базовый класс `SQLConnection` с общим функционалом
- **`postgre.js`** - Драйвер PostgreSQL с пулом соединений
- **`postgre.sync.js`** - Синхронизация схемы для PostgreSQL
- **`lite.js`** - Драйвер SQLite
- **`lite.sync.js`** - Синхронизация схемы для SQLite
- **`store.js`** - Интеграция с файловым хранилищем

#### Дополнительные модули
- **`sync.js`** - Утилита синхронизации модели с базой данных
- **`base/`** - Базовые определения проекта
- **`docs/`** - Автоматически сгенерированная документация (JSDoc)

## 4. Ключевые концепции и возможности

### 4.1. Модель данных

Модель описывается декларативно в файлах `*.model.js` и `*.cfg.js`:

```javascript
scheme('mnote', 'Заметки', undefined, undefined, [
    table('note', 'Заметка', 'idObj', null, [
        field('title', 'Заголовок', string(255)),
        field('text', 'Описание', string()),
        field('owner', 'Автор', ref('user', 'restrict', true)),
        field('date', 'Дата создания', datetime(true)),
        method('toString', 'Вернуть как строку', function (o) { 
            return this.title 
        })
    ])
])
```

**Основные понятия:**
- **Модель** - единая структура, описывающая всю модель данных
- **Схема** - пространство имен (namespace) для группировки таблиц
- **Таблица** - описание таблицы БД и соответствующего класса
- **Конфигурация** - структура для хранения настроек (не создается в БД)
- **Поле** - описание поля таблицы с типом и метаданными

### 4.2. EDMObj и EDMData

**EDMObj** - базовый класс для всех объектов данных:
- Каждый объект соответствует одной строке таблицы
- Автоматическое преобразование типов данных
- Отслеживание изменений (`_values_`, `hasUpdates`)
- Разрешение ссылок на другие объекты
- Свойства и методы, определенные в модели

**EDMData** - фабрика классов и контейнер объектов:
- Создание и управление EDMObj
- Управление соединениями с БД (пул соединений)
- Кэширование объектов (`dic`, `cfg`)
- Отслеживание изменений (`updates`, `undo`)
- Проверка прав доступа (`testAccess`)
- Сериализация для клиента (`prepareData`)

### 4.3. SQLConnection

Базовый класс для работы с базой данных предоставляет:

**Базовые методы:**
- `exec(sql, params)` - выполнение запроса без результата
- `query(sql, params)` - скалярное значение
- `select(name|sql, params)` - список строк (сырой формат БД)
- `insert(name, value)` - вставка записи
- `update(name, value)` - обновление записи
- `delete(name, value)` - удаление записи

**Методы для работы с объектами:**
- `selectObj(name|sql, params)` - список EDMObj
- `insertObj(name, value|edmObj)` - вставка с созданием EDMObj
- `updateObj(name, value|edmObj)` - обновление EDMObj
- `deleteObj(name, value|edmObj)` - удаление EDMObj
- `saveData(changes)` - сохранение списка изменений в транзакции

**Автоматическая генерация SQL:**
- Построение запросов на основе модели данных
- Параметризованные запросы (защита от SQL-инъекций)
- Шаблоны SQL с макроподстановками
- Система фильтров (`$like`, `$in`, `$date`, `$order` и т.д.)

### 4.4. Синхронизация модели

Процесс приведения структуры БД в соответствие с моделью:

1. **Чтение настроек** - определение подключений к БД
2. **Сборка модели** - сканирование `*.model.js` и `*.cfg.js`
3. **Pre-скрипты** - выполнение сценариев до синхронизации
4. **Первый проход (pre)** - создание/изменение схем, таблиц, полей
5. **Второй проход (post)** - добавление индексов, ссылок, удаление исключенных объектов
6. **Post-скрипты** - выполнение сценариев после синхронизации

Все изменения выполняются в одной транзакции с откатом при ошибках.

### 4.5. Клиент-серверное взаимодействие

**Сервер → Клиент:**
1. Выполнение SQL-запросов
2. Создание EDMObj из результатов
3. Разрешение ссылок (`addRef()`)
4. Сериализация через `prepareData()` - разделение на `dic` (словарь объектов) и `data` (список ссылок)
5. Передача JSON на клиент

**Клиент → Сервер:**
1. Правка объектов на клиенте
2. Автоматическое формирование списка изменений
3. Передача изменений на сервер
4. Сохранение через `saveData()` в транзакции

## 9. Рекомендации по использованию

### 9.1. Настройка проекта

1. **Создать файл настроек** `*.settings.js`:
```javascript
settings({
    db: {
        default: {
            require: 'postgre',
            dbname: 'mydb',
            dbhost: 'localhost',
            dbuser: 'postgres',
            dbpass: 'password',
            dbport: 5432
        }
    },
    models: {
        '*': 'default'
    },
    store: {
        path: 'd:/data/store'
    }
})
```

2. **Создать модель данных** `*.model.js`:
```javascript
scheme('myschema', 'Моя схема', undefined, undefined, [
    table('mytable', 'Моя таблица', null, null, [
        field('id', 'ID', id()),
        field('name', 'Название', string(255))
    ])
])
```

3. **Синхронизировать БД**:
```bash
node sync.js
```

### 9.2. Использование на сервере

```javascript
const { edm } = require('edm');

async function handler(req, res) {
    let edmData = edm.getEDMData(req.user);
    let connection = await edmData.getConnection('myschema', 'mytable');
    
    try {
        let data = await connection.selectObj('mytable');
        await connection.addRef(); // Разрешить ссылки
        data = edmData.prepareData(data); // Сериализация
        res.json(data);
    } finally {
        await connection.free();
        await edmData.free();
    }
}
```

### 9.3. Использование на клиенте

```javascript
// После загрузки библиотеки EDM
this.edmData = edm.getEDMData();

// Загрузка данных
$.get('/api/data')
    .then(data => {
        data = this.edmData.parse(data); // Десериализация
        // Работа с объектами
    });

// Сохранение изменений
let changes = this.edmData.getChanges();
$.post('/api/save', changes);
```

## 10. Заключение

**EDM** - это мощная библиотека для разработки трехзвенных приложений с использованием Node.js и SQL-баз данных. Она значительно упрощает работу с данными, автоматизируя многие рутинные задачи и предоставляя удобный объектно-ориентированный интерфейс.
